# Interface design

Spectra's gateway uses the Apple-inspired design specification generated by
`npx getdesign@latest add apple`. The generated [`DESIGN.md`](../DESIGN.md) is
the visual source of truth for the UI: a quiet white and parchment canvas,
near-black emphasis surfaces, Action Blue (`#0066cc`), a system SF/Apple font
stack, generous display type, hairline separators, compact pill actions, and
reduced chrome. It is an independently authored design analysis distributed by
getdesign, not an official Apple design system.

The application remains server-rendered with FastAPI/Jinja and its existing
local JavaScript. This keeps upload review/confirmation, transaction editing,
financial formatting, and the gateway's API contracts on their existing paths.
React and Tailwind are not part of the runtime: a second client build pipeline
would add no behavior needed for this visual change and would make the local
offline install harder to maintain. The single [`apple.css`](../src/spectra/web/static/apple.css)
layer applies the generated tokens after the existing component stylesheet;
the original selectors and API-driven states remain the same.

The shared shell now includes grouped navigation, a local-data status, and a
consistent import action. Dashboard, transactions, upload/review, budgets,
trends, subscriptions, and settings share the same type, spacing, control, and
surface rules. Status and empty-state marks use local SVG/CSS rather than emoji,
and button/action labels stay undecorated while their keyboard focus remains
visible. The shell remains responsive, preserves the existing light/dark
preference, supports reduced-motion preferences, and keeps keyboard access for
the upload drop zone. Review confirmation errors stay visible with the staged
batch available for a corrected retry. Long learning-history tables scroll
inside their own mobile container. The stylesheet and all other UI assets are
served locally; no CDN or remote font is needed at runtime.

To refresh the design reference intentionally, run `npx getdesign@latest add
apple` at the repository root and review the resulting `DESIGN.md` before
changing `apple.css`. That command needs npm registry access during development;
normal builds and app startup do not.
